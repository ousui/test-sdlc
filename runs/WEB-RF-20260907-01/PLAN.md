# WEB-RF-20260907-01 · Web 真实流程回归

## 权威与目标

用户批准的三场景工作包；替代旧 Client 五场景的执行范围，不恢复暂停中的 Client。标准是现有稳定 Spec，能力是 bundled SKILL/Runtime，执行者是本次 Web AI。以真实产物、上下游衔接、业务功能及测试结果为判据；不开展主观 UI/UX、三宿主安装认证、生产部署或 GitHub Provider 开发。

- Spec 起点：`ousui/sdlc-ai-spec@7a454c76b62c41525fa3990dffdaa9a52b975679`。
- 实验与修复分支：两仓库均为 `verify/web-realflow-v1`。
- 主记录：本仓库 Issue #1。
- `main`、`fixed/full-verify` 和上游项目分支不修改；空实验仓库 main 仅初始化入口。

## 范围与验收

### SG-26 · SpringGear JDK 26

来源：`ousui/springgear@e855096ff19dcdb303dc4250ba19c30acd743ac7`。当前 reactor 的 build、parent、core、bom 四模块为升级范围；禁用模块不伪称已验证。JDK 26 正式工具链编译、执行现有测试、增加核心工作流/代理/异常回归并打包成功；显式处理注解处理器、依赖兼容和测试发现。不能只改版本字符串，不能 skipTests 或发布到 Maven Central。原项目及实际差异保留。

### ADMIN-01 · 极简管理项目

来源：`pallets-eco/flask-admin@7fee0246b05476fb6bc38e44bcfb7cc87b978853` 的 `examples/auth_flask_login`，保留许可证。采用已有登录示例，避免为 sqla 示例另造整套身份系统。单需求：用户启用/禁用、后台筛选与修改；禁用用户不能新登录，已有 session 下一次受保护请求立即拒绝；重新启用不能复活已撤销会话。数据库持久化、匿名访问与正常用户路径都需要测试。仅修复本需求相关安全/兼容问题。

### FAN-01 · 从零粉丝网站

用户原始需求：做一个杨千嬅主题的个人粉丝网站，Go + jQuery + HTML，基本展示、粉丝账户、音乐试听、相册及简单后台。采用单体与本地持久化，明确普通用户/管理员边界。前台只能访问已发布内容；后台管理用户、音乐、相册和基础内容；音乐播放器必须可实际取流，资料修改与登录注销必须可用，保存的数据重启后可恢复。试听与照片使用自有测试媒体，不提交未经授权的艺人音频/图片，不冒称官方。

测试必须覆盖：匿名/粉丝/管理员授权、会话撤销、非法输入、CSRF、数据关联、已发布/草稿隔离、删除/下架后可见性、音乐取流和相册持久化，以及组合用户旅程。UI 美观不作门禁，但所需页面、表单和 jQuery 与后端的功能连接仍要检查。

## 流程与产物

逐项目 CTX → REQ → DSN → PLN → IMP → VFY → 适用 RLS，穿插只读 Status。按 Spec Disposition 决定独立阶段，不套用人为固定模板跳过规则。正式读写通过 Runtime/ArtifactStore；人可读 Markdown 为投影，不成为第二份权威。每阶段保留输入、实际调用结果、规范正文及完整成员；代码变更、测试日志、失败与修复记录分别归集。

每个问题：记录失败 → 归因到环境/输入/业务/Skill → 最小修复 → 定向回归 → 受影响下游重验 → 继续。不删除失败，不降低既定验收，不把固定 Fixture 测试当本轮业务场景。最终同一修复版本复核三场景链路及必要回归，保留版本映射。

## 能力与诚实边界

本 Web 容器不能联网；已验证用 GitHub Actions 获取精确源快照/依赖并由连接器下载 Artifact 的路径。业务命令可在受控 CI 执行，标记执行位置。SKILL 指引和真实 Runtime 调用不等于 Codex 原生加载；原生宿主认证为 OUT_OF_SCOPE。

没有可调用的独立 AI 子 agent，不伪造第二模型或人工 reviewer。客观合规采用实际独立进程重新读回、重算和核对的 deterministic reviewer；记录其检查范围与身份，不能把有限程序复核包装成独立语义或人工体验认证。缺少实际授权/证据的项目不签通过。正式效果遵守 Runtime 现有目标边界，不为测试绕过沙箱。
